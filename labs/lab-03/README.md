## Постановка задачи

Нужно сделать консольное приложение, в котором можно вести дневник тренировок:
записывать дату, вид нагрузки и длительность в минутах, а потом смотреть,
искать и удалять записи. Отдельно нужна статистика: сколько всего времени
ушло на тренировки, сколько было тренировок каждого вида и какая из них самая
длинная. Данные должны храниться в файле и не пропадать между запусками.

## Что умеет программа

- загружает записи из `data/workouts.json` при старте;
- показывает все тренировки, новые сверху;
- добавляет тренировку с проверкой даты и длительности;
- ищет по виду тренировки, дате или тексту заметки;
- удаляет запись по ID;
- считает общее время, среднюю длительность и статистику по видам;
- сохраняет файл после добавления и удаления, а также при выходе;
- не падает на пустом вводе, неверных числах, битом JSON и отсутствии файла.

## Формат файла данных

`data/workouts.json` это JSON-массив объектов. Один объект описывает одну
тренировку:

```json
[
  {
    "id": 1,
    "date": "2026-11-15",
    "kind": "Бег",
    "duration": 35,
    "note": "Пробежка в парке"
  }
]
```

Поля:

| Поле | Тип | Что означает |
|------|-----|--------------|
| `id` | целое число | уникальный номер записи |
| `date` | строка | дата в формате `ГГГГ-ММ-ДД` |
| `kind` | строка | вид тренировки |
| `duration` | целое число | длительность в минутах |
| `note` | строка | заметка, может быть пустой |

Файл записывается в UTF-8 с отступами, чтобы его было удобно читать и
редактировать руками. Если файла нет, программа стартует с пустым дневником и
создаёт его при первом сохранении. Если JSON повреждён, рядом появляется копия
`workouts.json.bak`, а работа продолжается с пустым списком.

## Используемые коллекции

- **`list[Workout]`** это основное хранилище. Список удобен тем, что сохраняет
  порядок записей, по нему просто перебирать элементы, искать и удалять.
- **`dict[str, KindSummary]`** используется в статистике. Ключ это вид
  тренировки, значение это количество, суммарное время и средняя длительность.
  Словарь даёт быстрый доступ к итогам по виду без повторного перебора всего
  списка.
- **`set[int]`** применяется при загрузке файла, чтобы отловить одинаковые ID
  и не пустить в список дубли.

Получается как раз связка `list + dict`, которая рекомендована для темы №9.

## Обработка ошибок

| Ситуация | Что делает программа |
|----------|----------------------|
| Файла данных нет | стартует с пустым списком и создаёт файл при сохранении |
| Файл повреждён, внутри не JSON | делает копию `workouts.json.bak` и начинает с пустого списка |
| В JSON не массив | делает копию файла и начинает с пустого списка |
| Одна запись битая | пропускает её, пишет причину и загружает остальные |
| Два одинаковых ID | вторую запись пропускает с сообщением |
| Пустая строка в обязательном поле | просит ввести значение ещё раз |
| В длительности не число | повторяет запрос |
| Длительность вне диапазона 1..1440 | повторяет запрос |
| Дата в неизвестном формате | подсказывает примеры `2026-11-21` и `21.11.2026` |
| Дата в будущем | не принимает её и просит другую |
| ID для удаления не найден | сообщает об этом и возвращает в меню |
| Нет прав на запись | сообщает об ошибке, данные остаются в памяти |
| Ctrl+C или Ctrl+D | корректно завершает работу и сохраняет данные |

## Ограничения

Редактирования уже созданной записи нет: проще удалить её и добавить заново.
Время тренировки хранится только в минутах, без часов и секунд. Файл данных
обычный JSON, поэтому его можно случайно испортить руками, но программа
сделает резервную копию и не упадёт.
