# Исходники диаграмм — ЛР1

Здесь хранятся **исходники**, а не только экспортированные картинки.

- `.drawio` — draw.io / diagrams.net
- `.puml` — PlantUML
- `.mmd` — Mermaid

Рекомендации:

- Имена по смыслу: `architecture.drawio`, `as-is.drawio`, `to-be.drawio`.
- Если диаграмма менялась, сохраняйте версии отдельными файлами, а не
  перезаписывайте единственный исходник.
- Экспорт (`png`/`svg`) можно положить рядом — он нужен для отчёта, но
  редактируется всё равно исходник.
