# Домашние задания

ДЗ по программному коду сдаются через **Pull Request**: преподаватель видит
`diff`, коммиты и может оставить комментарии к строкам.

## Порядок сдачи

1. Обновить `main`:
   ```bash
   git switch main
   git pull
   ```
2. Создать ветку под задание:
   ```bash
   git switch -c hw-01
   ```
3. Положить работу в `homework/hw-01/` (код, README с запуском, при необходимости
   тесты и диаграммы).
4. Закоммитить небольшими логичными коммитами.
5. Отправить ветку и открыть PR:
   ```bash
   git push -u origin hw-01
   ```
6. Заполнить шаблон PR (`.github/pull_request_template.md`), дождаться ревью.
7. После одобрения — **Merge pull request**, затем удалить ветку.

## Структура задания

```text
homework/
└── hw-01/
    ├── README.md      # что сделано и как проверить
    ├── src/           # код
    ├── tests/         # тесты, если есть
    └── diagrams/      # исходники диаграмм, если есть
```

## Требования к PR

- Ветка создана от актуального `main`.
- Нет секретов, `.env`, `.venv/`, `.idea/`, `.vscode/`.
- README объясняет, как запустить и проверить работу.
- Код соответствует [`docs/code-style.md`](../docs/code-style.md).
- В PR нет посторонних изменений (например, случайного форматирования всего
  проекта).
