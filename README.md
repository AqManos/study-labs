## Как оформить лабораторную

1. Создать папку `labs/lab-NN` (шаблон — `labs/lab-01`).
2. Заполнить `README.md`: цель, задание, что сделано, как запустить, выводы.
3. Положить отчёт в `report/`.
4. Положить **исходники** диаграмм в `diagrams/` — `.drawio`, `.puml`, `.mmd`,
   а не только экспортированные картинки. Если диаграмма менялась, рядом можно
   хранить версии «как было» и «как стало».
5. Код (если есть) — в `src/`.
6. Обновить таблицу в [`labs/README.md`](labs/README.md) и в этом файле.
7. Закоммитить в отдельной ветке. Для ДЗ — открыть Pull Request, для ЛР —
   уточнить у преподавателя, нужен ли PR или достаточно push в `main`.

## Работа с Git

Подробная шпаргалка — [`docs/git-workflow.md`](docs/git-workflow.md). Коротко:

```bash
# один раз: представиться
git config --global user.name "Имя Фамилия"
git config --global user.email "you@example.com"

# склонировать репозиторий
git clone <URL>
cd <папка-репозитория>

# перед началом работы — забрать свежие изменения
git pull

# новая задача — новая ветка
git switch -c lab-01

# цикл работы
git status
git add .
git commit -m "docs(lab-01): добавлен отчёт"
git push -u origin lab-01
```
